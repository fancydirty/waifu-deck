# Security policy

Waifu Deck stores access keys on the phone and encrypts cloud copies with a key derived from your password, so security bugs matter here.

## Reporting a vulnerability

Please report it privately through [GitHub's private vulnerability reporting](https://github.com/fancydirty/waifu-deck/security/advisories/new) instead of opening a public issue. Include the app version, what an attacker could do, and how to reproduce it. You will get a reply within a week.

## Scope

In scope: the Android app in this repository, including the sync engine, the encryption of cloud copies, and how credentials are stored.

Out of scope: the image sources themselves, and the security of the storage service you connect (R2, B2, Google Drive and so on).
